# features/bengali/ — Bengali-first features (Phase 4)

Placeholder for Bengali-first features: IME, TTS, offline dictionary/Wikipedia.

Planned contents:
- ime/          — Bengali input method (IBus/Fcitx5)
- tts/          — Bengali text-to-speech
- dictionary/   — offline Bengali dictionary + Wikipedia mirror
- fonts/        — Bengali fonts (fonts-noto-bengali, already in Phase 1)

Hard constraints:
- Bengali is an OPTIONAL feature — not the boot default
- Boot default remains en_US.UTF-8 (all-English)
- Bengali locale (bn_IN.UTF-8) available but not default
