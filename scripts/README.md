# Scripts

This directory will contain build and bootstrap scripts for Sayanox OS.

Planned scripts:

- `build-base.sh` — Create Minimal Debian rootfs using debootstrap
- `enter-chroot.sh` — Enter the built system
- `install-sayanox.sh` — Bootstrap Sayanox language inside the system
- `setup-branding.sh` — Apply Sayanox OS identity

More scripts will be added as Phase 1 and Phase 2 progress.
